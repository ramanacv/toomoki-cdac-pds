# Maharashtra PDS Gaps Implementation Plan

This planning note is reset to the current POC/MVP scope.

Current implemented chain:

```text
Procurement Centre -> FCI -> State Godown -> Issue Point -> FPS -> Beneficiary
```

Current stakeholder scope:

- `PROCUREMENT_CENTER`
- `FCI`
- `STATE_GODOWN`
- `ISSUE_POINT`
- `FAIR_PRICE_SHOP`
- `DISTRICT_SUPPLY_OFFICE`

Broader government policy tiers, commodity-processing actors, intermediate buffer nodes, welfare institutions, and cooked-meal/canteen channels are reference context only. They should be introduced later as separate modules if the product scope requires them.
