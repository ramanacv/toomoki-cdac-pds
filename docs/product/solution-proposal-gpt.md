# Superseded Solution Proposal

This earlier proposal described a broader supply-chain model with processing and sub-district buffer nodes. It has been superseded for the current POC/MVP.

Current app scope is:

```text
Procurement Centre -> FCI -> State Godown -> Issue Point -> FPS -> Beneficiary
```

Use `docs/product/entities-roles-permissions.md`, `docs/product/prd.md`, and the shared `StakeholderType` enum as the current source of truth.
